# CardEater 道具重做：A / B / C 方案

状态：B 方案已选定，并在 v0.21 中实现。A/C 保留为后续对照；旧道具、小牌组倍率、大牌组倍率和额外餐盘扩容道具均不再进入候选池。

## 研究结论

《幸运房东》的关键并不是“道具很多”，而是道具会改变符号之间的生产关系：生成器被 Conveyor Belt 放大，摧毁通过 Compost Heap 变成新的生成，Fruit Basket 给整个水果族群共同出口，X-Ray Machine 则需要“矿石来源 + 摧毁者”两端同时成立。它也保留少量稳定底分道具，但真正能形成记忆点的是规则改写、发动机连接和带风险的生成。

Essence 系统进一步把普通道具变成有条件的大突破：它使用独立池，通常在条件满足后自毁并兑现强效果。这类“先看见目标、再亲手点燃”的结构比无条件倍率更容易制造高潮。

对 CardEater 的共同约束：

- 不再用牌组张数、餐盘容量或“少拿牌”作为道具奖励条件。
- 道具必须至少完成一种职责：提供燃料、转换燃料、放大结果、改写规则。
- 三选一固定为：一件当前体系可用、一件跨体系桥梁、一件高潜力规则改写；刷新后仍保持这个结构。
- 道具说明只写“触发 → 结果”，所有进度直接显示为 `2/3`，不让玩家猜内部状态。
- 爽感集中在“发动机连续触发”和“突破完成”，普通动作只做轻反馈；不使用屏幕震动。

## A：单层流派遗物

每件道具永久生效，获得后立即能懂、立即能触发。首版制作 24 件：六条流派各三件专属件，再加六件跨体系桥梁。

代表设计：

| 道具 | 触发 → 结果 | 流派职责 |
|---|---|---|
| 果核标本 | 每轮首次达到水果连击 3 → 生成一张弱化随机水果 | 水果的燃料 |
| 果酱回声 | 水果连击中断 → 保存一半层数；下一张水果从保存层数继续 | 水果的容错 |
| 丰收印章 | 每吃第 5 张水果 → 一张随机水果吃点永久 +1 | 水果的长期出口 |
| 碎屑堆肥桶 | 每摧毁 3 张牌 → 生成一张弱化梨子 | 摧毁转生成 |
| 焚化账本 | 本轮被摧毁牌的正基础点数 → 轮末再结算一次，上限 12 | 摧毁的分数出口 |
| 回收烙印 | 生成牌被摧毁 → 令本轮下一张生成牌两面各 +2 | 生成摧毁闭环 |
| 红字弹簧 | 卡牌点数被降低 → 按降低量储存弹簧；恢复时等量释放为分数 | 降低恢复闭环 |
| 修补金缮 | 一次恢复超过原始点数 → 溢出值转为永久成长 | 恢复的长期出口 |
| 辣油量杯 | 连续硬吃 → 第 2 次免除负分，第 3 次把原负分转为正分并清空 | 硬吃终结器 |
| 反常餐巾 | 正确处理牌 → 储存 1 层保险；硬吃时消耗并额外 +3 | 正确流桥接硬吃 |
| 无底转盘 | 同一张牌可以无限后置 | 排序规则改写 |
| 果皮粉碎机 | 摧毁水果 → 视作水果连击 +1，并给堆肥计数 +1 | 水果桥接摧毁 |
| 低温榨汁槽 | 恢复水果点数 → 生成其弱化复制品，每轮一次 | 恢复桥接生成 |
| 辣味堆肥 | 硬吃生成牌 → 结算后摧毁它，并给下一次硬吃 +2 | 硬吃桥接摧毁 |

表现：触发道具从道具栏弹出一次，分数沿短轨迹飞入总分；三件以上连续发动时才进入连锁队列和递增音阶。

优点：学习成本最低、实现和调平最快。缺点：获得道具的瞬间很清楚，但单局中缺少一次“道具进化”的大高潮。

## B：普通道具 + 精华突破（推荐）

每件普通道具都自带一个可见的精华条件。普通效果保证立刻可用；条件完成后，精华外壳碎裂，道具永久进化。它借鉴《幸运房东》Essence 的“条件兑现”结构，但用 CardEater 的吃、弃、后置和永久点数变化设计全新内容。

实际落地的 15 件道具：

| 道具 | 普通效果 | 培养 / 精华效果 |
|---|---|---|
| 三格果篮 | 连续吃水果获得连击分，初始上限 +2 | 每吃 6 张水果首次突破；之后目标递增，奖励上限永久 +1，可无限培养 |
| 果核标本 | 每轮水果连击首次达到 3 时 +4 | 触发 3 次后突破，改为 +6 并生成弱化梨子 |
| 果皮引信 | 摧毁牌储存果火，下次吃水果时每层 +3 | 累计摧毁 5 张后，每层改为 +5 |
| 厨余发酵罐 | 每摧毁 3 张生成一张弱化梨子 | 累计摧毁 5 张后梨子不再弱化；继续培养提高新梨子点数，可无限培养 |
| 回收烙印 | 生成牌或弱化牌结算时 +3 | 结算 5 张后改为 +7 |
| 焚化账本 | 轮末每张本轮摧毁牌 +2 | 累计摧毁 8 张首次突破；之后永久提高单张收益，可无限培养 |
| 红字修复簿 | 每恢复 1 点红色降幅，本次 +1 | 累计恢复 8 点首次突破；之后永久提高倍率，可无限培养 |
| 锈蚀弹簧 | 降点储存锈力，正确处理最多释放 2 点，每点 +1 | 释放 8 点后，容量改为 4 且每点 +2 |
| 裂纹金缮 | 完成 3 次恢复后，当前牌较高一面永久 +1 | 突破后每次恢复都令当前牌两面永久 +1 |
| 铁胃通行证 | 每轮第一次硬吃抵消牌面负分 | 累计硬吃 6 次后，每轮第 3 次硬吃还会把负分翻正 |
| 辣油量杯 | 连续硬吃获得连击分，初始上限 +2 | 累计硬吃 6 次首次突破；之后永久提高上限，可无限培养 |
| 反常餐巾 | 正确处理存一层保险，硬吃消耗并 +4 | 消耗 4 层后，可存 2 层且奖励改为 +7 |
| 回转餐车 | 同一张牌每轮可以后置 2 次 | 累计后置 8 次后允许无限后置；继续培养提高每次后置得分，可无限培养 |
| 三拍出餐钟 | 每轮第 3、6、9…次行动 +4 | 触发 4 次首次突破；之后永久提高节拍奖励，可无限培养 |
| 双向餐叉 | 吃与弃交替时 +2 | 交替 6 次首次突破；之后永久提高交替奖励，可无限培养 |

三选一算法：

1. 第一格从永久牌组和本轮活动识别到的现有体系中抽取专属件。
2. 第二格必须是连接两个体系的桥梁件，优先保证至少一端已经成立。
3. 第三格固定为后置、节奏或硬吃方向的规则改写件。
4. 已拥有或曾经领取的道具不再重复进入候选；刷新后仍保持三种槽位职责。

表现：道具栏常驻环形进度；临界触发时先暂停卡牌局部动画约 80ms，再按“条件完成 → 外壳碎裂 → 新规则盖章 → 分数继续结算”的顺序播放。音效使用同一主题的四级音阶，进化时补全和弦。没有屏幕震动。

优点：最接近《幸运房东》的道具成长逻辑，也最适合 15 轮里制造 1–2 次明确高潮；玩家能讲出“这局我的果篮进化了”。缺点：需要新增道具进度、进化状态和触发队列，工作量高于 A。

## C：餐桌装置与连锁线路

把道具彻底做成 CardEater 自己的系统。餐盘周围有三类装置位：供料器、加工器、出餐器。所有装置都使用统一的输入/输出词汇，玩家看到的不是被动列表，而是一条会动的生产线。

示例线路：

- 水果连击 → 果汁槽产生“果浆” → 发酵罐消耗果浆生成牌 → 焚化口摧毁生成牌并结算分数。
- 点数降低 → 锈蚀秤产生“锈片” → 修复钟恢复点数 → 金缮盘把溢出恢复转为永久成长。
- 硬吃 → 辣酱泵产生“辣度” → 铁胃炉在 3 辣度时翻转一次负分 → 回味铃把翻转结果复制给下一张牌。

每三轮仍然三选一，但重复获得同一装置会升到二级或三级，而不是增加占用。跨体系装置可以把一种资源转换成另一种，因此水果、摧毁、恢复和硬吃不是四条孤岛。

表现：资源点从当前卡牌飞向对应装置，再沿线路逐个点亮；结算队列显示 `水果 ×4 → 果浆 2 → 生成 1 → 摧毁 1 → +18`。强连锁使用速度渐快、音高渐升、最终统一入账的演出，餐盘和装置动，屏幕不动。

优点：视觉辨识度最高，最能让玩家一眼看懂“餐盘是本轮桌面上的牌”，也最有自己的品牌。缺点：需要新的装置槽 UI、资源协议和更多美术；首次版本最容易因信息过量影响手机端。

## 建议与验收

建议选择 B。它比 A 更能解决“缺少爽感”，又不需要像 C 一样重做整个桌面。C 可以在 B 的触发队列稳定后，作为后续大版本把部分道具物理化。

无论选择哪一套，都用同一组验收：

- 初始三轮内至少有一件候选能与现有牌组直接互动。
- 水果连击、生成摧毁、降低恢复、硬吃四条流派各有启动、转换、出口，且至少各有两件跨体系桥梁。
- 一局不会出现三件都无法触发的候选。
- 连锁结算逐项可追溯，跳过动画后结果完全一致。
- 手机端道具正文不小于 11px，关键进度不小于 12px。
- 关闭音效、开启减少动态效果时，规则信息仍然完整。
